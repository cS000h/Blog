这是一篇示例文章，也是写给以后的自己的使用说明。读完可以删掉，或者改成你自己的内容。

## 两种篇幅

**笔记**是短的，一两句话也行，会直接完整显示在首页的时间线上。**文章**是写得完整一点的，首页只显示标题和摘要，点进去才是全文，还会自动生成目录和阅读进度条。

### 什么时候写笔记

脑子里冒出一个想法、看到一句话、解决了一个小问题，都可以是一条笔记。

### 什么时候写文章

几条相关的笔记攒多了，或者某件事想完整地讲清楚，就写成文章。

## 栏目

每条记录可以属于一个栏目，比如“课程学习”“游戏开发”“今日见闻”。栏目在 `src/config.ts` 里定义，加一行就多一个栏目[^1]。

在文件开头写上 `section: gamedev`，这条记录就会出现在“游戏开发”栏目里。

## 在手机上写

1. 打开 GitHub 上的仓库，进入 `src/content/notes`。
2. 点 **Add file → Create new file**，文件名用日期开头，比如 `2026-11-26-something.md`。
3. 写几行字，点 **Commit changes**。
4. 一两分钟后，网站自动更新。

> 文件名开头的日期就是这条记录的日期，所以连 `date` 都可以不写。

[^1]: 栏目的 `id` 会出现在网址里，最好用英文；显示的名字可以是中文。
